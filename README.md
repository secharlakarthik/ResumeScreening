# 📄 Resume Screening AI

An AI-powered Resume Screening System that analyzes resumes, extracts candidate information, matches resumes with job descriptions, and provides candidate rankings based on skill similarity.

---

## 🚀 Features

- Upload Resume (PDF/DOCX)
- Resume Parsing
- Candidate Profile Extraction
- Skill Extraction
- Job Description Matching
- Resume Score Calculation
- Candidate Ranking
- Dashboard
- User Authentication (Login/Register)
- Profile Wizard
- Settings Page
- Toast Notifications

---

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
```

Go to project folder

```bash
cd ResumeScreening-main
```

Install dependencies

```bash
npm install
```

---

## ▶️ Running the Project

### Start Backend

```bash
npm run server
```

or

```bash
ts-node server.ts
```

---

### Start Frontend

```bash
npm run dev
```

Open browser

```
http://localhost:5173
```
